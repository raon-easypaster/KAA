13단계 배포 프로세스

아래 13개 단계를 순서대로 따라하면 나만의 웹페이지를 가질 수 있습니다.

01 제미나이에서 HTML 생성 및 저장

1~3단계: 콘텐츠 변환

제미나이 도구에서 Canvas를 선택하고 내용을 입력하세요. "깃허브용 HTML" 요청이 핵심입니다.

Gemini Canvas 활성화
4~5단계: 로컬 파일 저장

코드를 복사하여 메모장에 붙여넣은 후 반드시 index.html로 저장해야 첫 페이지로 인식됩니다.

index.html 파일 생성

02 깃허브 저장소 생성 및 파일 업로드 (6~10단계)

  • 06
    GitHub.com 접속 및 계정 회원가입/로그인
  • 07
    우측 상단 + 버튼 클릭 후 New repository 선택
  • 08
    저장소 이름 입력 및 Public(공개) 선택 후 Create repository 클릭
  • 09
    Add file > Upload files 클릭하여 index.html 드래그 & 드롭
  • 10
    하단의 녹색 Commit changes 버튼 클릭하여 파일 저장
GitHub Repository Upload

03 GitHub Pages 최종 무료 배포 (11~13단계)

페이지 설정 (11~12단계)

  • 11 저장소 상단 Settings 메뉴 탭 접속
  • 12 좌측 Pages 클릭 ➔ Branch를 main으로 선택 후 Save 클릭

배포 완료 & 접속 (13단계)
